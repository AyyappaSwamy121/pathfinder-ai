## 3–5 Minute Golden Path Walkthrough

### 1. Problem & Positioning (0:00 - 0:30)
- Navigate to `http://localhost:3000/`.
- Highlight core thesis: *"Traditional platforms recommend courses. PathFinder recommends a path between where you are and where you want to go."*

### 2. Conversational AI Onboarding (0:30 - 1:00)
- Click **Build My Path** (`/onboarding`).
- Step 1: Input text prompt:
  > *"I'm a CSE student with Python and SQL experience. I have done two ML projects and want to become an AI Engineer within six months."*
- Step 2: Observe Layer 1 NLP profile extraction (`Python`, `SQL`, `AI Engineer`). Edit or confirm details.
- Step 3: Observe intelligent state build.

### 3. Learner Dashboard & Next Best Action (1:00 - 1:45)
- View `/dashboard`.
- Point out **Career Readiness Score** (e.g. 64% with deterministic formula explanation).
- Highlight **Next Best Action** card: *"Master Model Evaluation Metrics (45 mins)"*. Click **"Why this?"** to view prerequisite explanation.

### 4. Deterministic Topological Roadmap (1:45 - 2:30)
- Navigate to `/roadmap`.
- Explain 5-phase structured roadmap built from DAG topological ordering.
- Highlight resource cards, project deliverables, and milestone assessment badges.

### 5. Interactive Skill Knowledge Graph (2:30 - 3:00)
- Navigate to `/skills`.
- Interact with the **React Flow** graph showing 40+ skills and prerequisite connections.
- Observe node coloring (`Mastered`, `Developing`, `Locked`, `Recommended Next`).

### 6. Micro-Assessment & Adaptive Replanning (3:00 - 3:45)
- Navigate to `/assessment` or click assessment from roadmap.
- Complete 3 multiple choice questions on Model Evaluation.
- Submit low score or select *"Need Practice"* feedback $\rightarrow$ observe system automatically update learner profile and inject remediation step into roadmap!

### 7. What-if Career Simulator (3:45 - 4:15)
- Navigate to `/simulator`.
- Select **Data Scientist** as target comparison.
- Show instant computation: 72.7% Skill Overlap, shared skills, new required skills, and estimated 4 weeks additional effort.

### 8. Grounded AI Career Copilot (4:15 - 5:00)
- Navigate to `/copilot`.
- Click prompt chip *"What should I focus on this week?"*.
- View grounded answer referencing live readiness score, current gap, and next action.
